# Roadmap

Ideas, roughly in order. Open an issue to discuss any of them, or to propose your own.

- Editor: line numbers, find in file, go to line, tree-sitter highlighting.
- Diffs: hunk navigation and staging single hunks.
- Fonts and key bindings in the config file.
- Prompt titles for more agents (Gemini CLI, …).
- Optional LSP completion, per language.
- macOS support.

# Code of conduct

mira adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the
work. Harassment, insults, discrimination and personal attacks are not tolerated, in any
project space (issues, pull requests, discussions) or when representing the project.

## Reporting

Report unacceptable behavior privately to the maintainer,
[@IGUNUBLUE](https://github.com/IGUNUBLUE), through a
[private security advisory](https://github.com/IGUNUBLUE/mira/security/advisories/new) if
it can't be raised openly. Reports are handled confidentially. The maintainer may remove
content and restrict or ban participants, following the Covenant's enforcement guidelines.
